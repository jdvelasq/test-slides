# Mejoras agénticas incorporadas

Se actualizaron las diapositivas 020, 023, 024, 025, 033, 034, 053, 054, 057 y 058, conservando las 60 diapositivas y su numeración.

La presentación desarrolla ahora la separación entre pasos fijos e interpretación, recuperación de fallos, ejecución local frente a inferencia remota, encargos para subagentes, preparación del contexto, funciones de skills y herramientas, puntos de avance entre sesiones y evaluación con casos conocidos, incompletos y contradictorios.

La práctica 058 enlaza `assets/ejercicio-continuar.txt`: guardar entregas, continuar en otra sesión, resolver dos casos adicionales y reconocer la ausencia de una fuente. Incluye comprobaciones esperadas y una alternativa manual para usuarios de chat.

Referencias de contenido: notas locales de agentic-playground sobre Building effective agents, context engineering, Agent Skills, subagentes, estado y memoria, fallos, observabilidad y testing. No se añadieron instrucciones de instalación ni afirmaciones nuevas sobre disponibilidad comercial.
