2017 · Token: el modelo no lee palabras, lee fragmentos

Un token es un fragmento de texto: a veces una palabra completa, a veces un trozo de palabra o un signo.

Como referencia aproximada, una página de texto equivale a unos cientos de tokens.

Todo se mide en tokens: cuánto texto cabe en una conversación, cuánto cuesta una respuesta y cuánto consume tu límite de uso.

Cuando una herramienta dice "contexto de 1 millón de tokens", habla de cuánto puede leer de una sola vez.

El problema

Anthropic publica el Model Context Protocol (MCP) como estándar abierto.

Cada aplicación de IA necesitaba una integración distinta con cada servicio (Drive, Gmail, Notion, una base de datos...).

La solución

Lo que tú ves

Un enlace común. Un servicio se conecta una vez por MCP y funciona con cualquier aplicación compatible: Claude, ChatGPT, Gemini, Cursor y otras.

No dice "MCP": en las aplicaciones aparece como "conectores" o "integraciones". Cuando en redes dicen "conecté Claude a mi Notion" o "MCP para Excel", hablan de esto.
